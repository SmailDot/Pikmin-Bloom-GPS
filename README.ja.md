# Pikmin Bloom GPS

[繁體中文](README.md) ｜ [English](README.en.md) ｜ **日本語**

**ピクミン ブルーム**向けの、おおきな花をめぐる巡回アシストアプリです。root は不要です。表示言語は英語・繁体字中国語・日本語で、
スマホの言語に合わせて自動で切り替わります（Android 13 以降は「設定 → アプリ → 言語」でこのアプリだけ別の言語にもできます）。

## 機能
- **巡回**：地図におおきな花を登録すると、「帰宅」を押すまでアバターが花から花へ歩いて巡回します。
- **巡回中の歩数**：歩いた距離を歩数としてヘルスコネクトに書き込むので、ゲームのなえが育ちます。
- **帰宅**：実際の位置まで歩くかワープで戻るか、登録した家（家 1、家 2…）へ行ってそこで待機できます。
- **今すぐ向かう／到着したら待機**：おおきな花をタップしてそのまま向かいます。「到着したら待機」は着いたら一時停止するので、夜のうちに動かしておいて朝に報酬を受け取る使い方ができます。設定した距離（初期値 15 km）より遠いときは、歩く（歩数を書き込む）か乗り物を使う（歩数なし）かを先に確認します。
- **乗り物**：その他・車・飛行機。速度は自分で設定でき、歩数は書き込みません。次のおおきな花に着くと徒歩に戻ります。
- **フローティングバーとジョイスティック**：ゲームの上から一時停止・帰宅・乗り物の切り替えができます。ジョイスティックは好きな位置にドラッグでき、大きさは 3 段階です。
- **自動探検（実験的）**：フローティングバーのボタンを一度押すと、ゲーム内の自動編成で探検リストの果実と苗の探検をまとめて派遣します。赤いギフトとキノコには触れません。初期値はオフで、Android 11 以上とユーザー補助サービスのオンが必要です。実行中だけゲーム画面を読み取り（スクリーンショットは保存しません）、タップします。
- **自動餵精華（実験的）**：ゲームの餵精華の画面で、フローティングバーの旗ボタンから始めます（「ミツをあげる」と回数を選択）。各回で吹き出しに表示されているミツを現在のパーティに与え、花びらを収穫します。花が残っていれば再度なぞります。通知から停止できます。検知リスクは自動探検と同じで、ゲーム側からユーザー補助がオンだと分かる可能性があり、ご自身の判断でお願いします。
- **実際の位置への切り替え**：Google マップを使うときなどに、一時的に実際の GPS をスマホに戻し、あとで仮想位置に戻れます。
- **近くのおおきな花の候補を検索**：OpenStreetMap から近くのランドマークを候補として取り込みます。
- **中断したところから再開**：システムにアプリを終了されても、同じ場所・同じ状態から続けられます。

## 動作環境
- Android 9（API 28）以降。歩数機能は Android 14 以降（ヘルスコネクト内蔵）が必要です。
- 開発者向けオプション → **仮の現在地情報アプリを選択** → Pikmin Bloom GPS。

## 初期設定（アプリの「初期設定」画面で 1 つずつ確認できます）
1. 位置情報と通知の権限、「他のアプリの上に重ねて表示」（フローティングバー用）。
2. 開発者向けオプション → 仮の現在地情報アプリを選択 → このアプリ。
3. ヘルスコネクトの歩数と距離の読み取り・書き込み権限。
4. **⚠ ヘルスコネクトで歩数の「データソースと優先度」を開き、「Pikmin Bloom GPS」を追加。**
   いちばん忘れやすい手順です。これをしないと歩数は書き込まれても 1 日の合計に入らず、ゲームから読めません。
5. このアプリを電池の最適化の対象外にします（HyperOS では自動起動も許可）。
6. ピクミン ブルームの設定で、歩数の取得先を**ヘルスコネクト**にします。ヘルスコネクトでピクミン ブルームに歩数の読み取り（バックグラウンドを含む）を
   許可し、ゲームの位置情報の権限は「常に許可」にします。
7. 「Google 位置情報の精度」をオフにするのがおすすめです（設定 → 位置情報 → 位置情報サービス）。位置が実際の場所へ飛んで戻る可能性が下がります。

> ゲームがスマホ本体の歩数計で歩数を数える設定だと、ハードウェアの歩数計を読むため、どのアプリからも書き込めません。必ずヘルスコネクトを使ってください。

## 使い方
1. 地図を**長押し**しておおきな花を追加するか、「近くのおおきな花の候補を検索」で候補を取り込みます。
2. 「巡回開始」を押してから、ゲームで花植えを始めます。
3. 到着通知が出たら、ゲームでおおきな花をタップし、下にスワイプしてミツを集めます。
4. 終わるときは「帰宅」を押します。実際の位置まで戻ると、アプリが擬似位置を自動で止めます。

## 主な設定
| 設定 | おすすめ |
|---|---|
| 歩く速度 | 初期値 18 km/h（実測でいちばん安定）。上限は 20。19〜20 だとスマホが熱で引っかかったときに一気に進むことがあり、ゲームに乗り物とみなされる可能性があります。 |
| 到着したら待機：何 km を超えたら移動方法を確認するか | 初期値 15。0 にすると確認しません。 |
| 到着後、おおきな花の円内を周回 | 初期値はオフ。1 つのおおきな花を咲かせたい（300 本）ときだけオンにします。 |
| 歩幅 | 70 cm。距離 ÷ 歩幅で歩数を計算します。 |
| 1日の歩数上限 | 空欄なら上限なし。ゲームのなえの成長上限に合わせるなら 50000 と入力します。 |
| 自動探検（実験的） | 初期値はオフ。ユーザー補助サービスで、実行中だけゲーム画面を読み取り、タップします。どのアプリからもこのサービスがオンだと分かり、ゲーム側にも気付かれる可能性があります。ご自身の判断でお使いください。 |

## ビルド
JDK 21 と Android SDK（platform 37）が必要です。
```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
```
リリース署名はリポジトリの**隣**にある `../keystore/keystore.properties`（`storeFile`、`storePassword`、`keyAlias`、`keyPassword`）を読みます。
リポジトリの中には置かないでください。このファイルがないとリリース APK は署名されず、インストールできません。

adb でインストールして、仮の現在地情報アプリに設定する方法：
```bash
adb install -r -g app/build/outputs/apk/debug/app-debug.apk
adb shell appops set app.pikminbloom.gps android:mock_location allow
```

## おおきな花の位置について
Niantic はおおきな花の座標を公開していません。おおきな花は Wayspot に生えるので、このアプリは OpenStreetMap の Overpass API で
近くのランドマーク（記念碑、パブリックアート、寺社や教会、遊び場など）を**候補**として取得します。実際におおきな花があるのは
およそ 3〜6 割なので、あったものだけ残してください。OpenStreetMap のデータは ODbL ライセンスです。
